# Cyber GEC Club — Python Programming Course

**GitHub description:** A six-part, project-based Python course for Cyber GEC Club members. Build a Student & Lab Management System while learning Python fundamentals, functions and recursion, data structures, OOP, JSON persistence, exception handling, and testing.

## Six labs
1. Python fundamentals — variables, data types, input/output, conditions, loops, validation.
2. Functions, scope & recursion — reusable functions and recursive algorithms.
3. Data structures — lists, dictionaries, sets, tuples, searching, attendance, rankings.
4. OOP — classes, objects, inheritance, dunder methods.
5. File I/O & exceptions — JSON persistence and safe error handling.
6. Integration & testing — integrate, test, document, and demonstrate the project.

## Goal
Build a command-line application to register fictional club members, record lab scores and attendance, calculate averages, rank students, and save/load records safely.

## Getting started
1. Install Python 3.
2. Download or clone this repository.
3. Open it in VS Code or another editor.
4. Complete labs in order; read each lab's README.
5. Run a file using `python3 path/to/file.py`.

Use fictional data only. Never commit passwords, API keys, or private student information. Test normal inputs, invalid inputs, and edge cases. Do not silently overwrite corrupted data.
