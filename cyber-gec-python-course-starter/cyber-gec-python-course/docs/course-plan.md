# Course Plan — Cyber GEC Club Python

Six Saturday sessions, approximately two guided hours per session, plus practice between sessions.

| Part | Topic | Deliverable |
|---|---|---|
| 1 | Fundamentals and validation | Registration and score validator |
| 2 | Functions, scope, recursion | Reusable functions and recursive score total |
| 3 | Data structures | Search, attendance, and rankings |
| 4 | OOP | Student and club management classes |
| 5 | File I/O and exceptions | Safe JSON save/load |
| 6 | Integration and testing | Working application and test evidence |
